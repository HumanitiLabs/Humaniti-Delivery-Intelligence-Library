# Margin Leakage Assessment™

Version 1.0

The Margin Leakage Assessment™ evaluates the hidden operational, governance, resource, and delivery issues that reduce project profitability.

The objective is to identify where margins are being lost before profitability is permanently impacted.

---

# Assessment Overview

Dimensions:

1. Scope Control
2. Resource Efficiency
3. Delivery Performance
4. Governance Effectiveness
5. Financial Visibility

Each dimension:

0–20 Points

Total Score:

100

# Scoring Scale

1 = Strongly Disagree

2 = Disagree

3 = Neutral

4 = Agree

5 = Strongly Agree

---

# Dimension 1 — Scope Control

Questions:

1. Scope is clearly defined.
2. Scope changes are documented.
3. Change requests follow a process.
4. Scope creep is rare.
5. Project boundaries are enforced.

---

# Dimension 2 — Resource Efficiency

Questions:

1. Resources are allocated effectively.
2. Utilization targets are realistic.
3. Rework is minimized.
4. Staffing decisions support profitability.
5. Resource conflicts are rare.

---

# Dimension 3 — Delivery Performance

Questions:

1. Projects meet delivery commitments.
2. Milestones are achieved consistently.
3. Delivery delays are uncommon.
4. Delivery performance is predictable.
5. Project execution supports margin targets.

---

# Dimension 4 — Governance Effectiveness

Questions:

1. Decisions are made efficiently.
2. Escalations are controlled.
3. Governance does not create delays.
4. Approval processes are effective.
5. Leadership intervention is limited.

---

# Dimension 5 — Financial Visibility

Questions:

1. Project profitability is visible.
2. Margin forecasts are accurate.
3. Margin risks are identified early.
4. Financial performance is monitored.
5. Profitability reporting supports decision making.
